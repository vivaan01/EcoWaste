# ♻️ EcoWaste - Sustainable Waste Management Platform

EcoWaste is a web-based platform designed to revolutionize how residential communities manage and recycle waste. By leveraging technology, awareness, and gamified incentives, EcoWaste promotes proper disposal of solid and e-waste, integrates scheduled pickups, tracks recycling habits, and encourages responsible behavior through a point-based reward system.

---

## 📌 Features

- 🧠 **Awareness & Education**: Educational modules and statistics on waste impact.
- ♻️ **E-Waste Tracking**: Submit and monitor e-waste disposal activities.
- 🚚 **Scheduled Pickups**: View, schedule, or cancel recyclable pickups.
- 🎖 **Reward System**: Earn points for responsible actions and redeem them.
- 📈 **Real-Time Analytics**: Insightful graphs to track user and community engagement.
- 🧾 **Recycle Shopping**: Purchase items made from recycled waste using earned points.

## 🧪 Methodology

The platform uses modular component-based design in React, emphasizing scalability and user interaction. It utilizes React Router for navigation and Chart.js for visualizations. Each page addresses one of the five pillars of sustainable waste management:
1. **Awareness**
2. **Infrastructure**
3. **Community Engagement**
4. **Behavioral Change**
5. **Technology Integration**
